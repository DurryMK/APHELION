# APHELION

在疏密不均的星群与漫长的虚空之间，带着一颗微小天体开始漂流。聚集质量，孕育生命，让文明在引力、碰撞与敌意中延续。

## 成长与生存

从 Dust 陨石起步，通过低速碰撞融合，形成 Core 行星；随后利用引力捕获陨石，将卫星吸收为自身质量。也可以选择更高档位开始旅程。

行星依次成长为 **Luna → Mars → Terra → Gaia → Halo → Titan**。更高的质量带来更大的人口容量，人口壮大后，文明会自主研究科技，逐步拥有护盾、激光、人造卫星、太空城与空间跃迁。达到行星质量上限后，额外吸收的质量用于扩展太空城。

你负责引导天体，生命自行发展与战斗。其他文明互相敌对，游荡的巢穴舰队同样威胁着生存。留意危险预警，避开 Sol 恒星、Pulsar 中子星与 Void 黑洞的强大引力。

## 操作

- **WASD**：推进与转向，松开后惯性滑行，反向推进可制动。
- **K / L**：循环选择陨石卫星 / 吸收；也可单击选择、双击吸收。
- **T**：解锁跃迁后选择可见的空旷落点，左键确认，右键或 Esc 取消。
- **滚轮 / O**：缩放视野 / 切换漂流轨迹。
- **空格**：暂停，查看操作或返回起点。

每漂流一秒，便是一年。记录你的旅程距离，守护逐渐繁盛的世界。游戏每秒自动保存文明至当前浏览器，覆盖上一份存档，载入后进入新的沙盒；离线期间不成长。后台页面受浏览器调度限制，保存间隔可能延长。
