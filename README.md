# 微光 · SOLAR

原生 HTML、CSS 和 Canvas 2D 太空沙盒，无第三方依赖，无外部图片或音频。直接用现代浏览器打开 `index.html` 即可游玩，无需安装、构建或启动服务器。

## 操作

- 鼠标左键点击：沿点击时的方向持续推进。
- 点击玩家周围的圆环：关闭推进，保持惯性。
- 向运动反方向推进：逐渐制动。
- 滚轮：缩放视野。
- 空格：暂停或继续；O：切换轨迹；H 或 ?：显示操作说明。

| 类型 | 基础半径 | 颜色 | 质量门槛 |
| --- | --- | --- | --- |
| 小行星 | 2px | 灰蓝 | 0 |
| 岩质行星 | 3px | 赤褐 | 24 |
| 冰质行星 | 3.5px | 冰青 | 60 |
| 气态巨行星 | 4px | 琥珀 | 120 |
| 褐矮星 | 4.5px | 暗紫红 | 220 |
| 红矮星 | 5px | 珊瑚红 | 380 |
| 黄矮星 | 5.5px | 金黄 | 620 |
| 蓝巨星 | 6px | 电蓝 | 980 |
| 红巨星 | 7px | 橙红 | 1500 |
| 白矮星 | 4px | 冷白 | 2300 |
| 中子星 | 3px | 蓝紫 | 3400 |
| 黑洞 | 5px | 紫金 | 5000 |

尺寸对应 1× 视野下的半径，每档随质量最多增加 0.3px。光晕、光柱与星环不参与碰撞。初始质量为 8。低速碰撞可以合并，大质量天体吸收小质量天体；高速碰撞弹开并产生碎片。黑洞接触吸积。晋升为岩质行星后，可通过低速伴飞捕获小天体。

白矮星具有紧凑光环，中子星具有旋转双束光柱，红巨星具有脉动外层辉光，黑洞具有紫金吸积盘。白矮星、中子星晋升时实体缩小。类型顺序为游戏等级设定，不代表真实恒星演化路线。

新增环境天体中，65% 为低质量碎片，25% 为随玩家质量增长的吸收目标，8% 为同级附近天体，2% 为高阶目标。每两秒最多替换八颗视野外、无宿主且落后玩家至少三档的天体，逐步调整环境质量分布。玩家及其卫星保留。

引力使用软化牛顿模型，物理步长为 1/120 秒，使用 kick-drift-kick 积分。大型天体和玩家是引力源；普通碎片不计算彼此的微弱引力。碰撞使用空间网格和相对运动扫掠检测。吸收保留质量和线动量。卫星捕获包含局部径向耗散，黑洞星光偏折为视觉近似。远处普通天体移出模拟范围后回收，视野外持续补充天体。

## 文件

- `index.html`：界面与入口。
- `style.css`：布局和视觉样式。
- `game.js`：物理、生成、输入与绘制。

可在 `game.js` 顶部的 `TYPES` 中调整半径、颜色和成长门槛，在 `G`、`SOFTENING` 中调整引力。
