# APHELION

从一颗石头开始，直到上面的人开始抱怨房价。

在空旷的星群之间漂流，收集质量，孕育生命，带着不断壮大的文明寻找下一片资源。

## 养活一个世界

陨石通过低速碰撞融合，行星通过捕获并吸收陨石成长。生命从 10 百万人口起步，没有人口容量上限。人口越多、质量越少，消耗和生存压力越大；资源充裕时繁衍，资源紧张时人口回落、研究减速甚至停止。

陨石进入引力范围后，满足速度、质量差和掠过条件即可被捕获。各档天体具有明显的体积差，质量继续增长时，本体尺寸仍有上限。普通撞击同时考虑相对速度与双方质量比例，较重的一方损失比例更低。

所有天体的速度上限为 240，引力弹弓和撞击反弹同样受限。普通撞击先计算基础伤害，再按双方质量比的平方根修正：小天体承受放大后的伤害，大天体承受衰减后的伤害；同质量撞击保持原有伤害。

科技没有人口或行星等级门槛，发展后不会倒退。但人口低于 1 百万时，全部人口消亡、科技归零，护盾、城市与舰队一同损毁，留下天体与天然卫星，等待生命重新诞生。

主星质量没有上限，吸收和运输所得全部存入本体；最高档位和最大体积保持不变。主星不会因供养直接毁灭。战斗会损伤结构，完整度低于 30% 时破碎；补充质量可以修复损伤。

## 文明与舰队

文明逐级掌握护盾、轨道炮、轨道母舰、太空城与恒星采集技术。本体之外依次环绕两层城市、护盾、轨道炮与母舰。轨道炮最多三座，擅长近距离快速射击；母舰和轨道炮拥有独立耐久，都能被敌人击毁。

主星依次建造护盾、轨道炮、母舰和城市，各母舰独立生产飞船。人口越多，建造越快。轨道炮、母舰、城市和飞船随建造进度消耗本体质量，资源不足时暂停；护盾仍只需要时间。本体受击或被采集后，所有建造暂停五秒；外层受损不触发禁建。

撞击只伤害护盾、城市和本体，按从外到内的顺序消耗。城市拥有独立耐久，不储存质量、不参与引力和供养计算；界面保留原有名称。城市受损减少耐久和人口，本体受损减少质量、人口和供养能力。只有清除一个星球的全部人造产物后，飞船才能采集本体，采集会使当地人口锐减；货物运回卸载后才属于你。

城市、轨道炮和母舰在停止受击五秒后消耗本体质量自修。飞船只能靠港维修，不再瞬间恢复满血，维修同样消耗本体质量；资源不足时等待补充。护盾恢复不消耗质量。

飞船优先保护母舰，其次反击攻击主星与轨道炮的单位，再处理攻击自己的敌人。母舰被毁，其所属飞船立即消亡；巢穴同样遵守这条规则。

飞船采集陨石，不向陨石开火；轨道炮自动拦截射程内的外来陨石。青色淡虚线表示舰队探测范围，金色淡虚线表示各轨道炮的实际射程，引力与捕获共用一圈范围指示。

飞船需要弹药、续航和补给。主星越快，它们越不愿出航；突然加速可能把飞船留在身后。召回所有飞船后，会有十秒禁航期，让舰队重新集结。
主星平稳航行时，最多三分之一的现有飞船会在星系内伴飞巡航。舰船活动范围更广，速度更慢，转向和制动带有惯性；巡航飞船同样需要返港补给。

高等级文明和大质量天体较为罕见。恒星与脉冲星在后期可以被采集，虚空始终是不可开采的危险区域。

## 操作

- **WASD**：推进，松手滑行，反向推进制动。
- **K / L**：选择、吸收卫星；也可双击卫星吸收。
- **R / 右上角召回**：所有飞船返航，十秒内禁止出航。
- **滚轮 / O**：缩放视野、切换轨迹。
- **空格**：暂停并查看说明。
- **移动端竖屏或横屏**：按住空旷处推进，松手滑行；双击卫星吸收，双指捏合缩放，操作按钮位于右上角。
