# APHELION

原生 HTML、JavaScript、CSS 和 Canvas 2D 太空文明沙盒，无第三方依赖、外部图片或音频。入口为 index.html，无需构建。玩家成长止于行星，恒星、中子星和黑洞是独立的天然危险天体。

本轮实现尚未运行测试或浏览器验证，数值平衡留待实际游玩调整。

## 操作与存档

- WASD 推进，松开后惯性滑行，反向推进制动；斜向推进不增加加速度。
- K 循环选择已捕获的陨石卫星，L 主动吸收全部质量。单击选择、双击吸收也保留。
- T 开启跃迁选点，鼠标左键确认，右键、Esc 或再次按 T 取消。需要 4 级文明与太空城，冷却 60 秒，选点期间不暂停。
- 跃迁目标必须在当前可见范围内，本体及随行卫星的落点均须避开天体、舰船和天然危险圈。保留系统内相对位置、速度和卫星归属。
- 滚轮缩放，O 切换玩家轨迹；其他天体无轨迹，玩家与陨石卫星始终通过细线连接。
- 空格暂停：查看状态、规则，保存文明或返回起点。平时仅常驻左上角标题与天体信息。
- 左上角显示累计漂流距离与时间：游戏内 1 秒＝1 年，暂停不计时；距离按 1 世界像素＝1 km 显示累计移动路程，往返也累计，不受镜头与缩放影响，不计跃迁。存档距离数值保持不变；单位换算仅影响显示，不改变物理、人口、科技及战斗的计时速度。
- 仅主动操作触发暂停；窗口失焦、页面隐藏或最小化不进入暂停状态。失焦时清除方向键状态，避免持续推进。
- 开局可选择陨石、0 档原始行星或 1～6 档行星。高质量开局不会赠送科技，生命从初生阶段发展。
- 暂停面板手动保存覆盖同一浏览器内的单个存档。返回起点不自动保存；选择“载入文明”进入新沙盒。
- 保存本体与太空城质量、人口、科技、当前研究、护盾、孕育状态、健康质量峰值、跃迁冷却、击毁计数、累计漂流距离和游玩时间。不保存世界、舰船、陨石卫星、位置或速度，不计算离线成长。旧存档缺少历史距离时从 0 开始累计，保留原有游玩时间；重新保存后包含距离记录。
- 本地存储不可用或存档无效时直接显示原因，不迁移其他格式。游戏没有通关条件。

名称参照真实天体类别；质量、生命容量与成长顺序为游戏设定，不表示真实行星演化。档内半径最多增加 0.3px，主要依靠颜色和文明设施区分。

本体质量上限 3,200；超额吸收质量累计为太空城质量，无人为上限。未解锁太空城时可积累储备，解锁后才提供住房。太空城使基础人口容量增加 50%，每单位额外质量再增加 5,000 人口容量。5～6 档未建成太空城时暂用超级地球的基础容量。

跨质量门槛立即改变外观、容量和可研究的科技上限，保留已有实际人口和研究进度。质量下降时人口不能超过新容量。第 6 档不再提高科技上限、推进上限、基础引力范围或卫星数量；实际质量增加仍会增强吸力。

0 档开始孕育，首次孕育时间为 30 秒。孕育完成且达到 1 档后产生 20 人口；0 档孕育完成后进度停在 100%，提示继续吸收陨石至质量 24。提前进入 1 档会延续已有孕育进度；直接选择高档位开局也需要完成孕育。

人口采用逻辑增长，远低于容量时约 30 秒翻倍，接近容量逐渐放缓。科技发展同时受质量档位、人口容量和实际人口限制。实际人口达到下一科技门槛后才开始研究；跨过门槛之前的时间不计入研究。容量或人口不足时保留当前研究，停止推进；受伤仍按规则损失进度。

左上角进度条按状态分别显示陨石合并、生命孕育、下一科技人口门槛、科技研究。达到当前科技上限或完成 5 级科技后，显示人口相对总容量的增长。暂停面板显示对应数值、限制条件及保留的研究进度；科技等级显示已掌握级别，不随可研究上限下降而改写。

科技逐级发展。人口或质量档位下降时保留已解锁科技，新的研究仍需满足门槛。人口清零时文明消亡，科技与太空城功能清空，30 秒后重新产生生命。降回无人口容量的阶段同样失去文明。

环境行星也发展人口、研究科技，并定时吸收自身捕获的陨石。初始环境行星随机分配生命与文明阶段。环境太空城在受重创且跃迁可用时自主避险。

文明完全自主战斗。目标优先级为母舰、攻击舰、陨石、行星，同优先级攻击最近目标。不同文明互相敌对，自身及自己捕获的陨石不受本方攻击。玩家不能指定目标。人造卫星仅代表文明设施，不参与目标检测、不占捕获名额、不能被攻击。

## 引力、捕获与碰撞

- 陨石之间低相对速度碰撞可合并；其他普通天体碰撞弹开并受损。行星不能通过碰撞吞并，也不能捕获其他行星，不提供双星绑定玩法。自由天体仍可通过引力改变彼此轨迹。
- 陨石、行星、恒星、中子星和黑洞均参与双向引力，母舰、攻击舰及视觉设施完全不参与。单对天体的加速度向量为 G × 引力源实际质量 × 相对位置向量 / (距离平方 + 软化长度平方)^1.5，再乘外缘衰减。G 初值 60，软化长度取 6px 与双方半径平均值的较大者；行星引力质量包括太空城质量。
- 同一对天体共用双方较大的作用半径，最外侧 20% 用平滑函数衰减至零，保证双方引力作用与反作用对称。小天体自身标示范围之外仍可能受到大范围天体的吸引，也会产生相应反作用；双方范围之外不再交互。有限范围与近距离软化均为游戏近似。
- 玩家基础引力半径为环境同档天体的 70%，捕获半径再取宿主引力半径的 70%。外围淡虚线显示玩家引力范围，内侧点线显示捕获范围。恒星等天然天体的伤害半径单独配置，与这两类范围独立。
- 捕获要求：主星总质量严格大于陨石的 5 倍，有空余名额，并在捕获圈内侧向中速掠过。速度门槛由局部逃逸速度近似值乘以 1.2 后限制为 60～140px/s。正面接近进入碰撞处理，不捕获行星或舰船。
- 绑定后仍以 0.12rad/s 缓慢绕行，约 52 秒一圈，目标半径为 18px 至捕获半径的 75%。轨道控制仅替换宿主与卫星之间的相互作用，并施加反作用；不抵消其他天体的引力。宿主与卫星受到的外部引力差超过宿主束缚强度的 70% 时禁止捕获或解除绑定。出引力范围、速度过快、宿主消失、名额或质量比例失效也会脱离。
- 捕获不直接增加质量。K/L 或双击吸收重新检查归属、质量比例及捕获圈内距离，按双方总质量计算动量，吸收后只限制总速度。
- 玩家推进上限：陨石与 0 档 200px/s；1～5 档依次 250、300、350、400、450；6 档仍为 450。引力允许超过推进上限，总速度限制为推进上限的 3 倍，即 600～1350px/s。超出推进上限时，推进可转向、减速，不能进一步提速。自由环境天体总速上限为 2400px/s；舰船沿用独立速度规则。
- 普通撞击伤害为各自总质量乘以相对速度 / 600，比例限制为 2%～24%。激光和碰撞优先扣护盾，穿透部分先扣太空城质量，再扣本体；人口和当前研究按质量损失比例减少。
- 5 秒未受伤后护盾每秒恢复上限的 5%。太空城外壳不扩大物理碰撞半径，防御血量使用护盾。
- 健康质量峰值记录本体与太空城总质量的历史最大值。当前总质量损失超过峰值的 50% 即破碎；吸收可补回损失。陨石质量低于 0.6 也消失。
- 破碎不生成实体陨石或掉落物，仅有短暂光点。5 级文明击碎行星后直接获得其剩余质量的 50%，其他击毁不提供质量。击毁按陨石、行星、攻击舰、母舰分类计数。

天然恒星、中子星和黑洞分别采用 6px、3px、5px 基础半径，实际参与运动和相互吸引，不参与文明、捕获和玩家晋升，无法击毁。危险圈半径分别为 24、32、40px，圈内持续受损；接触恒星与中子星受伤并被排斥，接触黑洞直接摧毁。核心与危险圈均检测每个物理子步的相对扫掠路径，避免高速穿越漏判，黑洞核心不受碰撞冷却保护。恒星使用多层暖色光晕和脉动日冕；光晕、吸积盘、光柱与背景星光偏折只参与绘制。

自由天体初速度大小为 32 / (1 + 质量 / 24)^0.35 px/s，方向随机。质量越大，初始漂移越慢，玩家与天然危险天体同样适用。初速度是游戏初始条件，后续轨迹由引力及推进等作用改变。移动天体的引力可以改变飞掠天体的方向与速度，不额外赠送固定的弹弓加速。初始已绑定的陨石卫星采用宿主速度加绕行速度。读档时按本体与太空城总质量重新分配玩家初速度，不恢复旧速度。

附近天然危险天体，以及总质量超过玩家 3 倍的行星，会触发预警。交互范围或攻击范围外围 160px 内显示黄色提示；预测 3 秒内进入危险区时显示红色提示。优先显示危险最高、距离最近的 3 个目标，屏内用圆圈及三角标记，屏外用方向箭头，左上角显示名称和距离。预警复制当前天体状态，以同一引力模型和当前推进方向按 1/60 秒步长预测，每 0.3 秒刷新并缓存，不修改实际宇宙。预测不包含未来玩家操作、战斗、碰撞与卫星轨道辅助，因此属于短期估计。

## 巢穴舰队与宇宙密度

巢穴按固定世界区域随机分布，出生点 800px 内不生成巢穴。同时最多激活附近 3 处，远处休眠。母舰及其舰队状态在当前沙盒中保留，死亡母舰不重生。

每艘母舰最多保有 8 艘攻击舰，每 8 秒补充一艘。攻击舰累计攻击 10 次后必须返航，停靠 3 秒装填后再次出击。母舰被毁后剩余舰船消耗现有弹药，耗尽后停止攻击，无法补给。母舰及攻击舰均可被文明激光击毁。

母舰血量 100，攻击舰血量 12。母舰在 150px 内每 2 秒攻击一次，伤害 4；攻击舰速度 60px/s，在 90px 内每 1.4 秒攻击一次，伤害 3。攻击舰以母舰为中心在 300px 半径内活动，目标搜索距离同为 300px，不追击活动范围外的天体；活动边界移除向外速度。母舰被毁后保留其原位置作为活动中心。舰队无差别攻击陨石与行星，不攻击己方舰船和不可摧毁的天然天体。

母舰使用多面舰体、分层装甲、双引擎辉光、中央舰桥与停靠舱灯光。攻击舰停靠时舱灯改变颜色，母舰实体半径保持 12px，外观细节不改变战斗属性。config.js 的 nests.fighterSpeed、activityRadius 和 engagementRange 分别控制攻击舰速度、活动半径与目标搜索距离。

击毁攻击舰无收益。击毁母舰不提供质量，下一科技满足研究条件时追加 8 秒研究进度；科技已满或人口不足时没有研究收益。

宇宙采用疏密不均的区域星群，保留大片空旷地带。出生附近有两个疏松陨石小群，共 12 颗。初始尝试生成 110 个环境天体，补充目标 150 个，每 2 秒最多尝试补充 8 个；密度采样失败时不强行补齐。新生环境天体约 76% 陨石、22% 行星、2% 天然危险天体。远处普通天体退出模拟，视野外补充新的天体。

## 文件与配置

- index.html：入口、起始选择、暂停面板与 HUD。
- style.css：界面样式。
- config.js：档位、人口容量、科技门槛、成长速度、护盾与火力、碰撞损失、天然危险、跃迁与舰队参数。
- civilization.js：人口、研究、护盾恢复、文明消亡和重新孕育。
- gravity.js：引力计算、空间索引、潮汐、推进与总限速、物理子步数量和预警轨迹预测，不依赖 DOM 或 Canvas。
- game.js：物理、捕获、吸收、战斗、舰队状态机、跃迁、生成、存档、输入与绘制。

修改 config.js 中 civilization.incubationSeconds 调整首次孕育时长，rebirthSeconds 调整灭绝后重新孕育时长，growthDoublingSeconds 调整人口成长速度，civilization.technology 各项 research 调整科技节奏。gravity 配置引力常数、软化、范围、限速及子步；capture 配置捕获与轨道控制；initialMotion 配置初速度；warning 配置预警预测。环境分布参数位于 game.js 顶部的 POPULATION。

物理主步长为 1/120 秒，根据速度及加速度最多细分 8 次，每个子步完整执行 kick-drift-kick 积分、轨道检查及危险区和碰撞扫掠。引力与碰撞分别使用空间网格筛选。回收环境天体时保护可见区域及正在与其发生引力交互的邻域，避免刚出屏就移除引力源。文明每 0.5 秒更新，自动战斗每 0.1 秒更新。轨道辅助、限速、护盾、太空城和跃迁均为游戏化规则。
