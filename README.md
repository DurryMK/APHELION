# APHELION

从一颗石头开始，直到上面的人开始抱怨房价。

在空旷的星群之间漂流，收集质量，孕育生命，带着不断壮大的文明寻找下一片资源。

## 养活一个世界

陨石通过低速碰撞融合，行星通过捕获并吸收陨石成长。生命从 10 百万人口起步，人口越多，供养消耗越大；资源充裕时快速繁衍，过度拥挤时人口回落、研究减速。

主星不会因供养直接毁灭。战斗会损伤结构，完整度低于 30% 时破碎；补充质量可以修复损伤。

## 文明与舰队

文明逐级掌握护盾、近防炮、轨道母舰、太空城与恒星采集技术。母舰围绕主星运行，飞船自动作战、采集和运输：没有护盾的行星都可以采集，有护盾时必须先击破护盾。质量运回并卸货后才属于你。

飞船需要弹药、续航和补给。主星越快，它们越不愿出航；突然加速可能把飞船留在身后。召回所有飞船后，会有十秒禁航期，让舰队重新集结。
主星平稳航行时，最多三分之一的现有飞船会在星系内伴飞巡航。舰船活动范围更广，速度更慢，转向和制动带有惯性；巡航飞船同样需要返港补给。

高等级文明和大质量天体较为罕见。恒星与脉冲星在后期可以被采集，虚空始终是不可开采的危险区域。

## 操作

- **WASD**：推进，松手滑行，反向推进制动。
- **K / L**：选择、吸收卫星；也可双击卫星吸收。
- **R / 右上角召回**：所有飞船返航，十秒内禁止出航。
- **滚轮 / O**：缩放视野、切换轨迹。
- **空格**：暂停并查看说明。
- **移动端竖屏或横屏**：按住空旷处推进，松手滑行；双击卫星吸收，双指捏合缩放，操作按钮位于右上角。

支持中英文切换，每秒自动保存。新文明版本使用独立存档，旧版本记录仍保留在浏览器中。载入文明进入新宇宙，保留主星成长与研究记录，轨道设施和飞船重新建设；离线期间不成长。

没有终点。你负责在宇宙里闲逛，他们负责给每次转弯编写历史。
